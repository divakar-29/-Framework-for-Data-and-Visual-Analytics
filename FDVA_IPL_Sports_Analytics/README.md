# IPL Sports Analytics

## Project Overview
IPL Sports Analytics is a data visualization project developed as part of the Framework for Data and Visual Analytics (FDVA). It analyzes Indian Premier League match data to identify team performance, match outcomes, toss decisions, player awards, and venue statistics.

## Objectives
- Analyze IPL match datasets.
- Visualize match and team performance using Python and Matplotlib.
- Develop an interactive dashboard using Microsoft Power BI.
- Present useful insights from historical IPL data.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Microsoft Power BI
- IPL CSV datasets

## Project Files
- `matches.csv` – IPL match-level dataset.
- `deliveries.csv` – Ball-by-ball IPL dataset.
- `IPL_Sports_Analytics_Report.pdf` – Project report.
- `IPL_Sports_Analytics.pbix` – Power BI dashboard.
- Python visualization code and output graphs.

## Visualizations
The project includes visualizations of:
1. Matches won by each team
2. Toss decision distribution
3. Matches by season
4. Top venues
5. Player of the Match awards
6. Toss winner versus match winner
7. Match result types
8. Innings run distribution

## Conclusion
This project uses data visualization techniques to explore IPL match statistics and present the results through charts and an interactive Power BI dashboard.
